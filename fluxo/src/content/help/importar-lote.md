Onde você está:
Na tela de **Importação em Lote**, ferramenta essencial para subir centenas de faturas de uma só vez através de planilhas.

O que fazer agora:
- Baixe o modelo oficial de planilha CSV/XLSX.
- Preencha os dados seguindo rigorosamente as colunas solicitadas.
- Faça o upload do arquivo para validação.

Passo a passo:
1. Clique em "Baixar Modelo" para garantir que os campos estão corretos.
2. Prepare seus dados no Excel ou Google Sheets.
3. Arraste o arquivo para a área de upload.
4. Revise os dados validados antes de confirmar a criação das faturas.

Depois disso:
Após a importação bem-sucedida, as faturas aparecerão automaticamente na tela de Cobranças e entrarão na régua de comunicação.
