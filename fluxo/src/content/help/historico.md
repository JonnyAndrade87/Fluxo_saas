Onde você está:
No **Histórico de Mensagens**, onde você pode auditar todas as interações enviadas pelo sistema aos seus clientes.

O que fazer agora:
- Monitore se os e-mails e mensagens de WhatsApp foram entregues.
- Verifique o conteúdo exato das notificações enviadas.
- Filtre por cliente ou período para localizar interações específicas.

Passo a passo:
1. Use a barra de busca para encontrar um cliente específico.
2. Observe o status (Enviado, Entregue, Lido) para cada mensagem.
3. Se houver falhas, verifique o erro reportado na coluna de status.

Depois disso:
Se notar muitas falhas, verifique suas configurações de canal ou o cadastro de e-mail/telefone dos clientes.
